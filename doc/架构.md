# Agent 智能评测平台 — 后端架构

> 最后更新: 2026-05-15

---

## 项目结构

```
agent-test-platform/
├── pom.xml                      # 父 POM — 多模块聚合 + 版本管理
├── aun-common/                  # 公共层 — 零业务依赖
├── aun-framework/               # 框架层 — 配置、基础设施
└── aun-web/                     # 业务 + Web 层
```

### 依赖链

```
aun-common  ←  aun-framework  ←  aun-web
```

| 模块 | 职责 | 主要内容 |
|------|------|----------|
| `aun-common` | 公共基础 | `Response<T>`, `PageResult<T>`, `BusinessException`, `GlobalExceptionHandler` |
| `aun-framework` | 框架设施 | `CorsConfig`, `RestTemplateConfig`, `MyBatisPlusConfig` |
| `aun-web` | 业务入口 | `controller/`, `service/`, `mapper/`, `pojo/entity/`, `pojo/dto/` |

### 依赖明细

```
aun-common:
  └── spring-boot-starter-web
  └── spring-boot-starter-validation

aun-framework:
  └── aun-common
  └── spring-boot-starter-web
  └── mybatis-plus-spring-boot3-starter

aun-web:
  └── aun-framework
  └── mysql-connector-j
  └── hutool-all
  └── lombok
  └── spring-boot-starter-test
```

## 分层架构

```
┌──────────────────────────────────────────┐
│  controller/         REST 接口层         │  ← @RestController
├──────────────────────────────────────────┤
│  service/            业务逻辑层          │  ← @Service
│  service/impl/                           │
├──────────────────────────────────────────┤
│  mapper/             数据访问层          │  ← MyBatis-Plus BaseMapper
├──────────────────────────────────────────┤
│  pojo/entity/        数据库实体          │  ← @TableName
│  pojo/dto/           数据传输对象         │  ← 入参
└──────────────────────────────────────────┘
```

调用方向：`controller → service → mapper`，不可反向。

## 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

| code | 含义 |
|------|------|
| 200  | 成功 |
| 400  | 参数错误 |
| 404  | 资源不存在 |
| 500  | 服务器内部错误 |

分页响应 `data` 内嵌 `PageResult<T>`：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "data": [...],
    "total": 100,
    "page": 1,
    "pageSize": 20
  }
}
```

## 已实现接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/agents` | 分页查询 Agent |
| GET | `/api/agents/{id}` | Agent 详情 |

## 数据库

- **数据库**: MySQL 8.0
- **ORM**: MyBatis-Plus 3.5.7
- **表总数**: 14 张（全部定义在 `init.sql`）
- **命名规范**: 下划线命名，字段名由 MyBatis-Plus 自动映射到驼峰

### 核心 ER 关系

```
agent 1──M evaluation_task_agent M──1 evaluation_task
evaluation_task 1──M task_dimension M──1 evaluation_dimension
evaluation_task 1──M evaluation_result
evaluation_result 1──M evaluation_result_detail M──1 evaluation_dimension
evaluation_task M──1 dataset
dataset 1──M dataset_question M──1 question
question 1──M question_turn
evaluation_task 1──1 evaluation_report
```

## 外部 Agent 调用

```
评测平台(Spring Boot)                    被评测Agent
     │                                          │
     │── POST {agent.endpoint_url} ──────────→  │
     │   body: { messages: [...], ... }         │
     │   headers: { Authorization per auth_type }│
     │ ←── { choices: [{ message: {content} }] }│
     │                                          │
     │   timeout: 30s 读取 / 10s 连接            │
     │   鉴权: bearer / api_key / basic          │
```

使用 Spring Boot 自带的 `RestTemplate`，配置在 `RestTemplateConfig`。

## 版本管理

所有第三方依赖版本统一在父 `pom.xml` 的 `<properties>` 中定义：

| 依赖 | 版本变量 | 当前值 |
|------|----------|--------|
| Java | `java.version` | 17 |
| Spring Boot | (继承自 spring-boot-starter-parent) | 3.3.5 |
| MyBatis-Plus | `mybatis-plus.version` | 3.5.7 |
| Hutool | `hutool.version` | 5.8.28 |

子模块引用时不带 `<version>`，由父 POM 的 `<dependencyManagement>` 统一控制。
